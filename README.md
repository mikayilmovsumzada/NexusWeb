# NexusWeb

> **Where Ideas, People & Technology Connect.**

**NexusWeb** üç istiqamət üzrə qurulan yeni texnologiya ekosistemidir:

- **Məhsullar:** real problemləri həll edən proqram təminatı hazırlayırıq.
- **Təhsil:** kibertəhlükəsizlik, süni intellekt və proqram təminatı üzrə öyrənmə materialları (planlaşdırılır).
- **İcma:** ideya, bilik və layihə paylaşan insanları bir araya gətiririk (formalaşır).

Bu repoda NexusWeb-in rəsmi saytının kodu yerləşir.

## İlk məhsul: ContextPulse AI

**ContextPulse AI** proqramçıların fasilədən sonra işə tez qayıtmasına kömək edən və komanda rəhbərlərinə tıxanmaları işçiləri izləmədən göstərən platformadır. Hazırda **hazırlanma mərhələsindədir**.

- Məhsul səhifəsi: saytda `/products/contextpulse-ai`
- Mənbə kodu: [github.com/mikayilmovsumzada/ContextPulse-AI](https://github.com/mikayilmovsumzada/ContextPulse-AI)

**Komanda:** Nuran Əliyev (ideyanın müəllifi), Elgün Hüseynli, Mikayıl Mövsümzadə.

## Xüsusiyyətlər

- **İki dil:** Azərbaycan və ingilis dili, istənilən səhifədə bir kliklə dəyişir.
- **İşıqlı və qaranlıq tema:** cihazınızın ayarına uyğunlaşır, istəsəniz özünüz seçə bilərsiniz.
- **Hər ekrana uyğun:** telefon, planşet və kompüterdə rahat istifadə olunur.
- **Əlçatanlıq:** klaviatura ilə idarəetmə və ekran oxuyucuları dəstəklənir, "azaldılmış hərəkət" ayarı nəzərə alınır.
- **Məxfilik:** saytda analitika, reklam və izləmə alətləri yoxdur. Əlaqə formu ilə göndərilən mesajlar təhlükəsiz saxlanılır və yalnız NexusWeb komandası tərəfindən oxunur. E-poçt ünvanınızdan yalnız sizə cavab yazmaq üçün istifadə edirik.
- **Dürüst məzmun:** uydurma istifadəçi, rəy və ya rəqəm yoxdur. Hazır olmayan funksiyalar açıq şəkildə "Planlaşdırılır" və ya "Hazırlanır" kimi göstərilir.

## Texnologiyalar

Next.js 16, React 19, TypeScript, Tailwind CSS v4 və SQLite.

## Lokal işə salmaq

Node.js 24 və ya daha yeni versiya tələb olunur.

```bash
npm install
npm run dev
```

Sonra brauzerdə `http://localhost:3000` ünvanını açın.
